# במאי AI: עריכה אוטומטית לפי הטעם שלך

מטרה: לזרוק לאפליקציה צילומי גלם של סרטון המלצה, האול (haul) או ולוג, ולקבל גרסה ראשונה ערוכה **לפי הטעם שלך**, כפרויקט רגיל שאפשר לתקן ידנית.

## חלוקת עבודה

| מי                                 | מה                                                                                                               |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| **המנוע** (קוד רגיל, `src/engine`) | חיתוך שקט, קצב, זום, מעברים, התאמה לביטים, הרכבת הפרויקט. מהיר, חינמי, דטרמיניסטי.                               |
| **Claude** (קריאה ל־API)           | החלטות יצירתיות: אילו קטעים הכי טובים, איזה פתיח, באיזה סדר, מהם הפריטים בהאול, כיתוב לכל קטע, איזה סגנון מתאים. |
| **הטעם שלך** (פרופיל)              | מנחה את Claude בכל קריאה, ומתעדכן עם הזמן.                                                                       |

Claude לא צופה בסרטון כקובץ. האפליקציה שולחת לו:

- פריימים מייצגים (בערך אחד כל 3 שניות, JPEG קטן) עם חותמות זמן
- נתוני שמע: מפת שקט, שיאי עוצמה, ביטים
- סוג הסרטון (המלצה / האול / ולוג) ופרופיל הטעם

הוא מחזיר **תוכנית עריכה** במבנה קבוע (JSON), שהאפליקציה מאמתת ואז המנוע מבצע.

## תוכנית העריכה (הפלט של Claude)

```
{
  videoType: 'recommendation' | 'haul' | 'vlog',
  presetId,                       // בסיס לקצב, זום ומעברים
  hook: { assetId, inUs, outUs, reason },
  segments: [{ assetId, inUs, outUs, role, label, captionHe?, reason }],   // בסדר הסופי
  music: { energy: 'low'|'mid'|'high' },
  notesHe                         // הסבר קצר בעברית: מה נעשה ולמה
}
```

- **המלצה:** פתיח חזק (משפט הכי מעניין), מוצר, יתרונות, סיכום והמלצה.
- **האול:** מזהה כל פריט מהפריימים, מקבץ קטעים לפריט, שומר את הרגע הכי טוב של כל אחד.
- **ולוג:** בוחר רגעים מגוונים ואנרגטיים, מוריד חזרות, בונה קשת (פתיחה, אמצע, סוף).

כל קליפ שנוצר מסומן `origin: { by: 'auto', rule: 'ai', reason }`, כדי שתראי בכל קליפ למה הוא נבחר ותוכלי לשנות.

## פרופיל הטעם

נשמר במכשיר שלך (ובעתיד גם בקובץ שאפשר לייצא):

- **שאלון קצר בעברית:** קצב (רגוע / בינוני / מהיר), מוזיקה, כתוביות (גודל, מיקום, צבע), צבעים וסגנון, טון (חם, מצחיק, מקצועי), אורך יעד, מה בהחלט לא.
- **סרטוני דוגמה שאהבת:** האפליקציה מודדת מהם מקומית אורך חיתוך ממוצע, חיתוכים לדקה, אורך הפתיח ועוד. כמה פריימים מכל אחד נשלחים ל־Claude שמתאר את הסגנון, והתיאור נשמר בפרופיל.
- **למידה מהתיקונים שלך:** קליפ שהמנוע יצר ואת שינית (קיצרת, מחקת, הזזת) נרשם. מדי פעם Claude מסכם את התיקונים לכללי טעם חדשים ("מעדיפה פתיחים קצרים יותר") ומציע לעדכן את הפרופיל, ואת מאשרת.

## חיבור ל־Claude

- **מפתח API אישי:** פותחים חשבון ב־console.anthropic.com, יוצרים מפתח, ומדביקים אותו פעם אחת בהגדרות האפליקציה. הוא נשמר רק בדפדפן שלך ולא נשלח לשום מקום חוץ מ־Anthropic.
- **עלות:** תשלום לפי שימוש. סרטון גלם של כמה דקות עולה בערך כמה סנטים לעריכה. מומלץ להגדיר בקונסולה תקרת הוצאה חודשית.
- **פרטיות:** הפריימים הנשלחים עוברים ל־Anthropic. הסרטונים עצמם לא עוזבים את המכשיר.
- **אבטחה:** מפתח בדפדפן מתאים לשימוש אישי בלבד. אם נשתף עם אחרות, נעבור לשרת קטן שמחזיק את המפתח.
- **מודל:** ברירת מחדל Sonnet 5.5 (זול ומהיר). אפשר לבחור Opus 5.5 לתוצאה איכותית יותר.

## כתוביות בעברית: מגבלה חשובה

Claude לא שומע אודיו. כדי שיבין מה נאמר בסרטון (ובחירת פתיח לפי המשפט, כתוביות מדויקות, זיהוי פריטים לפי מה שאמרת) צריך תמלול. בדפדפן יש Whisper, אבל בעברית הוא פחות מדויק, וכבד באייפון (הורדה של כמה מאות MB). לכן:

1. **שלב א:** עורכים לפי תמונה ושמע בלבד (עובד היטב להאול וולוג, פחות להמלצות שנשענות על מה שנאמר).
2. **שלב ב:** מוסיפים תמלול. נבדוק Whisper בדפדפן על האייפון שלך ונחליט לפי איכות ומהירות.

1. **M6 ייצוא** – בלעדיו אי אפשר לפרסם שום דבר. (M5 טקסט ושמע נכנס קודם בגרסה קצרה.)

4. **A1–A4** ה־AI עצמו. משם והלאה הוא משתפר.
